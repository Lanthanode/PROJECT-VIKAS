CAPSTONE PROJECT 
Railway Management System 
Real-Life Example: Indian Railways Passenger Reservation 
1. Introduction 
Railway transportation handles a large amount of information related to trains, passengers, stations, 
reservations, seats and payments. Managing this information manually can lead to duplication, errors 
and difficulty in retrieving records. 
A Railway Management System is a database-based system that manages passenger reservations 
and railway-related information efficiently. 
For this capstone, we consider a real-life scenario similar to an online Indian railway passenger 
reservation system. A passenger searches for a train, selects a journey, reserves a seat and makes a 
payment. The system stores all these details in related database tables. 
2. Real-Life Scenario 
Consider a passenger named Rahul Sharma who wants to travel from Delhi to Mumbai. 
 Passenger → Searches for Train → Selects Train → Makes Reservation → Seat is Assigned → 
Makes Payment → Reservation Confirmed

8. SQL Operations Implemented 
DDL and DML: Used to create and populate Passenger, Train, Station, Reservation, Payment and 
Train_Station tables. 
Integrity Constraints: PRIMARY KEY, FOREIGN KEY, NOT NULL, UNIQUE, CHECK and DEFAULT 
constraints maintain data integrity. 
Simple Query: SELECT * FROM Passenger WHERE Age > 20; 
Nested Query: SELECT Name FROM Passenger WHERE Passenger_ID IN (SELECT Passenger_ID 
FROM Reservation); 
JOIN: SELECT P.Name, R.Reservation_ID, R.Seat_Number FROM Passenger P JOIN Reservation 
R ON P.Passenger_ID = R.Passenger_ID; 
View: CREATE VIEW Passenger_Reservation_View AS SELECT P.Name AS Passenger_Name, 
R.Reservation_ID, R.Seat_Number, R.Journey_Date FROM Passenger P JOIN Reservation R ON 
P.Passenger_ID = R.Passenger_ID;

13. Conclusion 
The Railway Management System demonstrates how a DBMS can be used to solve a real-world 
problem involving large amounts of interconnected data. 
The project combines database design, ER/EER concepts, relational tables, DDL, DML, integrity 
constraints, simple queries, nested queries, joins, views and triggers into one practical application. 
The system provides an organized way to manage passengers, trains, stations, reservations and 
payments while maintaining relationships and consistency among the stored data. 
Thus, the Railway Management System serves as a practical DBMS capstone based on a real-life 
railway reservation scenario.
